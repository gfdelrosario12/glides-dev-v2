## MODIFIED Requirements

### Requirement: The site features a responsive landing panel
The home page SHALL feature a responsive landing panel that includes a biography, profile imagery, and an embedded interactive terminal instance, immediately inviting visitors to explore the content model via terminal commands.

#### Scenario: Viewing the home page
- **WHEN** a visitor navigates to the root URL `/`
- **THEN** they see the landing panel containing the biography, the headshot image, and the embedded terminal component
