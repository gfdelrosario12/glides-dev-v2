## MODIFIED Requirements

### Requirement: Standalone networking page provides instant touch-first mobile access
The `/connect` route SHALL be optimized for mobile phone visitors arriving via QR code or NFC scan. Interactive endpoint buttons SHALL span full width with prominent tap targets, outdoor legibility, fast initial paint, and a direct escape link back to the main portfolio.

#### Scenario: Scanning QR code or NFC tap on mobile
- **WHEN** a visitor opens `/connect` on a mobile device
- **THEN** the identity and all communication endpoints are immediately visible and clickable above the fold without delay
